# ✅ To-Do List Application

## 📌 Project Description

The To-Do List Application is a Python-based command-line application designed to help users manage their daily tasks.

Users can add tasks, view their tasks, mark tasks as completed, and remove tasks from the list.

## 🎯 Features

* ➕ Add new tasks
* 📋 View all tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 🔄 Interactive menu
* 🖥️ Command-line interface

## 🛠️ Technologies Used

| Technology             | Purpose                        |
| ---------------------- | ------------------------------ |
| Python                 | Application development        |
| Lists                  | Store tasks                    |
| Functions              | Organize program functionality |
| Conditional Statements | Control application logic      |
| Loops                  | Display and manage menu        |

## ▶️ How to Run

### 1. Make sure Python is installed

Check Python:

```bash
python --version
```

### 2. Run the program

```bash
python todo_list.py
```

### 3. Use the menu

The application provides options for managing tasks.

For example:

```text
1. Add Task
2. View Tasks
3. Mark Task Complete
4. Delete Task
5. Exit
```
