# 🧮 Calculator with GUI

## 📌 Project Description

The Calculator with GUI is a Python-based desktop application that performs basic arithmetic calculations through a graphical user interface.

The application provides an easy-to-use calculator interface with buttons for numbers and mathematical operations.

## 🎯 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Number input through buttons
* 🧹 Clear button
* 🖥️ Graphical User Interface
* ⚡ Instant calculation
* ❌ Basic error handling

## 🛠️ Technologies Used

| Technology             | Purpose                        |
| ---------------------- | ------------------------------ |
| Python                 | Application development        |
| Tkinter                | Graphical User Interface       |
| Functions              | Organize calculator operations |

## ⚙️ How It Works

```text
Start Application
       ↓

       ↓

       ↓

       ↓

       ↓
```

## ▶️ How to Run

### 1. Make sure Python is installed

Check Python using:

```bash
python --version
```

### 2. Run the calculator

```bash
python calculator.py
```

The calculator GUI will open in a new window.

### 3. Perform calculations

Click the number and operation buttons to perform calculations.

For example:

```text
10 + 5 = 15
20 - 8 = 12
6 × 4 = 24
20 ÷ 5 = 4
```
